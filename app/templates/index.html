Architecture
🌐 Internet → ⚖️ ALB → 🖥️ EC2 + Docker → 🐘 PostgreSQL
  • Compute: EC2 (Amazon Linux 2023) in Auto Scaling Group, multi-AZ
  • Container: Docker (multi-stage, non-root), pulled from ECR
  • Networking: VPC with 2 public + 4 private subnets, 2 NAT gateways
  • Security: Chained security groups · SSM Session Manager (no SSH)
  • Database: RDS PostgreSQL , Multi-AZ with automatic failover
  • IaC: Terraform, remote state on S3
